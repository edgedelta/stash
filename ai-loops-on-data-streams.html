THE BUILDING BLOCKS
Why CLIs beat MCP for telemetry
Small context
Telemetry output is huge. The agent trims it with jq or head before the model reads it.
Composable
Pipes, jq, diff, kubectl, git. One shell line instead of many tool calls.
Familiar to models
Trained on years of shell usage. Fewer wrong calls, better recovery.
MCP still fits where there's no shell, or where you need scoped, governed access.
